Each GIF samples one complete animation cycle at 15 frames per second and loops indefinitely. GIF frame delays are rounded to centiseconds. The timing is illustrative and does not describe network latency or authorization duration.

To refresh the recordings, select each access mode on the website, capture a full cycle of its diagram, crop to the diagram bounds, and export a looping GIF. Keep the filenames above so both root READMEs continue to reference the local assets.
